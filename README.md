# سیستم نامه‌نگاری اداری - هتل نور حیات

**Nour Hayat Hotel - Administrative Letter Management System**

سیستم جامع مدیریت نامه‌نگاری و اتوماسیون اداری برای هتل نور حیات

## ویژگی‌های اصلی

### 📄 بخش نامه‌نگاری
- **نوشتن نامه جدید**: ایجاد نامه‌های اداری با تنظیمات فونت و پاراگراف شبیه Word
- **کارتابل نامه‌های صادره**: مشاهده و مدیریت نامه‌های ارسال شده
- **کارتابل نامه‌های وارده**: دریافت و مدیریت نامه‌های دریافت‌شده
- **جستجو و آرشیو**: جستجو در سوابق نامه‌ها بر اساس شماره، موضوع و تاریخ
- **سیستم تایید و ارجاع**: نامه‌های کارمندان برای تایید مدیر، و مدیران می‌توانند نامه‌ها را به کارمندان ارجاع دهند

### ⚙️ پنل مدیریت (برای IT)
- **مدیریت کاربران**: اضافه، ویرایش و حذف کاربران
- **مدیریت واحدها**: ایجاد و مدیریت بخش‌های مختلف
- **مدیریت نقش‌ها**: تعریف نقش‌ها و دسترسی‌ها
- **کنترل دسترسی**: تعریف دقیق دسترسی‌های هر نقش

## نقش‌های سیستم

1. **مدیر IT** - اختیارات کامل مدیریتی (فقط اضافه کردن کاربران)
2. **مدیر عامل** - تایید و نظارت بر نامه‌های سازمان
3. **مدیر کل** - مدیریت بخش و تایید نامه‌های بخش
4. **مسئول بخش** - تایید نامه‌های کارمندان و ارجاع به زیرمجموعه
5. **کارمند** - نوشتن نامه و ارسال برای تایید

## دسترسی‌ها

### دسترسی‌های مدیریتی
- مشاهده تمام نامه‌ها
- تایید و امضاء نامه‌ها
- مدیریت واحدها
- مدیریت کاربران

### دسترسی‌های IT
- **فقط**: اضافه کردن کاربران جدید
- مدیریت سیستم
- مشاهده تمام نامه‌ها

## شروع سریع

سیستم این به صورت **آفلاین** کار می‌کند و برای استفاده فوری آماده است:

1. صفحه لاگین را باز کنید
2. یکی از حساب‌های پیش‌فرض را استفاده کنید
3. داشبورد اصلی باز می‌شود
4. شروع به استفاده کنید!

## شروع به کار

### حساب‌های پیش‌فرض (Demo Accounts)

**1. حساب مدیر IT:**
- نام کاربری: `ADMIN`
- رمز عبور: `123`
- نقش: مدیر IT

**2. حساب مسئول بخش:**
- نام کاربری: `manager`
- رمز عبور: `123`
- نقش: مسئول بخش

**3. حساب کارمند:**
- نام کاربری: `employee`
- رمز عبور: `123`
- نقش: کارمند

### مراحل استفاده

1. **ورود به سیستم**
   - وارد نام کاربری و رمز عبور شوید
   - داشبورد اصلی نمایش داده می‌شود

2. **نوشتن نامه جدید**
   - کلیک کنید روی "نامه جدید"
   - از واحد (فرستنده) را انتخاب کنید
   - به واحد (دریافت‌کننده) را انتخاب کنید
   - موضوع نامه را وارد کنید
   - متن نامه را با تنظیمات فونت و پاراگراف بنویسید
   - "ارسال برای تایید" کنید

3. **کارتابل نامه‌های وارده**
   - نامه‌های دریافت‌شده را مشاهده کنید
   - می‌توانید نامه را به کارمندان ارجاع دهید (اگر مسئول باشید)

4. **مدیریت سیستم (برای IT)**
   - به پنل مدیریت وارد شوید
   - کاربران جدید اضافه کنید
   - واحدها را مدیریت کنید
   - نقش‌ها و دسترسی‌ها را تنظیم کنید

## ساختار دیتا‌بیس

### جداول اصلی
- **users**: اطلاعات کاربران
- **departments**: بخش‌های سازمان
- **roles**: نقش‌های سیستم
- **letters**: نامه‌های ثبت‌شده
- **letter_approvals**: تایید و ارجاع نامه‌ها
- **letter_history**: تاریخچه تغییرات نامه‌ها
- **letter_attachments**: فایل‌های پیوست شده به نامه‌ها
- **letter_archive**: آرشیو نامه‌ها برای جستجو

## تکنولوژی‌های استفاده‌شده

- **Frontend**: React, Next.js, TypeScript, Tailwind CSS
- **Backend**: Next.js API Routes, Supabase
- **دیتا‌بیس**: PostgreSQL (Supabase)
- **احراز هویت**: JWT Tokens with HTTP-only Cookies

## نکات امنیتی

- تمام رمزهای عبور با bcrypt هش شده‌اند
- استفاده از HTTP-only Cookies برای نگهداری توکن‌های احراز هویت
- Row Level Security (RLS) فعال شده است
- بازدادن سقوط‌های دریافت‌شده و قابل پیش‌بینی
